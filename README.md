#IT Helpdesk Ticket Submission Client and Ticket Management Administrator Applications.

# Prerequisites
Make sure you have Python installed on your system. The application uses majority of the python builtin libraries except 1,You will need to install the `customtkinter` library in your machine:

#Structure
The applications need to be stored locally on the machine in a same directory to function. Both applications are launched via their own respective terminal instance.
"Client.py": The client desktop applicatoin used by end-users to submit IT support requests.
"Admin.py": The IT manager desktop dashboard application used to view, update statuses, and delete submitted tickets.

#Execution
Open 2 separate terminal instances in the directory of the files.
 Run "python Client.py" to launch the Client side application
 Run "python Admin.py" to launch the Administrator side application

 The sqlite database is created automatically in the directory of the applications once the client.py is launched.
